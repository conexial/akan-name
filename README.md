# Akan Name Generator

## Project Description

Akan Name Generator is a simple web application that calculates the day of the week a user was born and gives them an Akan name based on their gender.

Akan names come from Ghanaian culture, where children are named according to the day of the week they were born.

## Features

- User enters birth day, month, and year
- User selects gender
- Application validates user input
- Application calculates the day of the week
- Application displays the correct Akan name
